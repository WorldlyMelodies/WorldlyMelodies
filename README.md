# Worldly Melodies — GitHub Pages Website

This folder is ready to upload to a GitHub repository.

## Quick start
1. Create a GitHub account at https://github.com/ if you do not already have one.
2. Create a new repository named `worldlymelodies`.
3. Upload `index.html`, `style.css`, and the `assets` folder.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select **main** and **/(root)**, then Save.
7. GitHub will show your website address.

## PayPal
The Donate button is intentionally waiting for your PayPal donation URL. Once you have it, replace the `href="#"` on the Donate link in `index.html` with your PayPal URL.
